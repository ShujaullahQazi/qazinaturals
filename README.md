# Qazi Naturals

Farm-documentary storefront for peesi hui khalis haldi (pure turmeric powder) with WhatsApp checkout.

## Stack

- Next.js (App Router, SSG)
- React 19

## Develop

```bash
npm install
npm run dev
```

## Deploy

Push to the connected Vercel project. Primary URL: https://qazinaturals.vercel.app
